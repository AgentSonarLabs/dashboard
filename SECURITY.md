# Security Policy

## Supported versions

Security fixes target the latest published release. Upgrade before reporting a vulnerability.

## Reporting

Do not report vulnerabilities in public issues, discussions, or pull requests. Once hosted on GitHub, use its private vulnerability reporting feature; otherwise contact a maintainer privately through the repository host. Include affected versions, impact, and reproduction steps. Do not attach real telemetry containing secrets or personal data. Maintainers will investigate privately and coordinate a fix and disclosure with the reporter. No response-time guarantee is made while this project is pre-release.

## Telemetry data

Telemetry can contain prompts, tool inputs, logs, identifiers, or other sensitive data supplied by the instrumented application. Minimize data before sending it to a collector and never include production secrets in reports.
